Calley App – Flutter Machine Test

📱 Project Overview

Calley App is a Flutter-based mobile application developed as part of the CS Technology Machine Test. The project focuses on user authentication, OTP verification, and REST API integration.

✨ Features

- User Sign Up
- User Sign In
- OTP Verification
- Language Selection
- REST API Integration
- User-friendly UI
- Error Handling

🛠️ Technologies Used

- Flutter
- Dart
- REST API
- HTTP Package
- Postman
- JSON

🔗 API Integration

The application uses the Mock API V2 backend for authentication and API communication.

API Base URL:
"https://mock-api.calleyacd.com/api"

Note: Registration API testing currently returns a 404 Not Found response. Endpoint verification is pending.

📂 Project Structure

lib/

 ├── features/
 ├── screens/
 ├── services/

🚀 How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Install dependencies:

flutter pub get

4. Run the application:

flutter run
